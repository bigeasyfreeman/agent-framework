# OpenClaw Agent Framework

A workspace structure for AI executive assistants running on OpenClaw.

## Quick Start

1. Copy this folder to your workspace (e.g., `~/clawd/`)
2. Edit `USER.md` with your info
3. Edit `IDENTITY.md` to customize your agent's personality
4. Start chatting - the agent will guide you through `BOOTSTRAP.md`

## Files

### Core
- `AGENTS.md` - Main instructions (read every session)
- `SOUL.md` - Personality and behavioral guidelines
- `BOOTSTRAP.md` - First-run setup (delete after complete)
- `SECURITY.md` - Security policies and patterns

### Personalization
- `USER.md` - Info about you (the human)
- `IDENTITY.md` - Agent's name, personality, origin story
- `TOOLS.md` - Notes on tools, APIs, and accounts

### Memory
- `MEMORY.md` - Curated long-term memory
- `memory/` - Daily notes (YYYY-MM-DD.md)
- `HEARTBEAT.md` - Periodic check-in tasks

### Work
- `tasks/lessons.md` - Lessons learned (reviewed at session start)
- `tasks/todo.md` - Active task tracking
- `references/` - Methodology guides and patterns

## Philosophy

The agent wakes up fresh each session. These files ARE its memory and continuity. The agent reads them, updates them, and evolves through them.

See `AGENTS.md` for full documentation.
